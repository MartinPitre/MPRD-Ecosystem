# UTA Theory

## Overview

This folder contains the theoretical foundation of **Uncertainty Transformation Analysis (UTA) v1**.

UTA was developed as a framework for examining how uncertainty changes over time as new information, discoveries, confirmations, disruptions, and memory effects influence human understanding of events, technologies, scientific developments, and knowledge systems.

The objective of UTA is not to determine whether an event is positive or negative, but rather to examine how uncertainty transforms as evidence accumulates and interpretations evolve.

---

## Core UTA Transformation Model

UTA v1 is defined by the following transformation equation:

**U_new = U_old − R + C + S − M**

Where:

| Variable | Description |
|----------|-------------|
| U_old | Initial uncertainty |
| U_new | Updated uncertainty |
| R | Resolution through evidence or confirmation |
| C | Complexity introduced by new information |
| S | Surprise or unexpected developments |
| M | Memory, familiarity, or historical stabilization |

The framework proposes that uncertainty is dynamic and may either increase or decrease depending on the interaction of these components.

## Relationship to the Pilot Study

The documents contained in this folder represent the conceptual foundation of UTA.

Empirical testing of the framework was conducted separately through the UTA Pilot Study, which includes:

- Anonymous participant evaluations
- Delayed repeatability testing
- Event stability analysis
- Participant stability analysis
- Event-type signature consistency analysis

Pilot materials are maintained within the Pilot directory of the UTA repository.
