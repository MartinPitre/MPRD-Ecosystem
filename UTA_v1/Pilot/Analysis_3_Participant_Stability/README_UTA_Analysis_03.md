# UTA Analysis 03 – Participant Stability

## Overview

This folder contains the materials associated with Analysis 03 of the UTA (Uncertainty Transformation Analysis) pilot study.

Analysis 03 evaluated participant-level stability by examining how consistently individual participants scored events between the Q1 and Q2 assessment periods.

The objective was to determine whether participants maintained reasonably stable scoring patterns when reassessing the same events after a delay period.

---

## Research Question

Do individual participants demonstrate stable uncertainty assessment behavior across repeated evaluations of the same events?

---

## Data Sources

The analysis was performed using the final preserved pilot datasets:

- UTA_Q1_Pilot_Dataset.xlsx
- UTA_Q2_Pilot_Dataset_Updated_v18.xlsx

Only the final corrected datasets were used for preserved analysis results.

---

## Method Summary

For each participant, corresponding Q1 and Q2 event scores were compared.

Absolute score differences were calculated at the event level and aggregated to produce participant-level stability measurements.

Lower mean score differences indicate greater participant stability between assessment periods.

Anonymous participant identifiers were used throughout the analysis.

## Significance

Participant stability provides insight into the consistency of individual scoring behavior within the UTA framework.

Analysis 03 helps evaluate whether delayed reassessments produce reasonably stable participant-level scoring patterns, supporting the reliability of the pilot methodology.
