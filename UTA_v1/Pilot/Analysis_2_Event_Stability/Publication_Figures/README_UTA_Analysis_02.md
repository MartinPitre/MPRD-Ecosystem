# UTA Analysis 02 – Event Stability Audit

## Overview

This folder contains the materials associated with Analysis 02 of the UTA (Uncertainty Transformation Analysis) pilot study.

Analysis 02 evaluated event-level stability by examining how participant assessments of individual events changed between the Q1 and Q2 assessment periods.

The objective was to identify which events demonstrated strong scoring consistency and which events exhibited greater variability over time.

---

## Research Question

Do specific events exhibit stable uncertainty assessment patterns when evaluated repeatedly by participants across separated assessment periods?

---

## Data Sources

The analysis was performed using the final preserved pilot datasets:

- UTA_Q1_Pilot_Dataset.xlsx
- UTA_Q2_Pilot_Dataset_Updated_v18.xlsx

Only the final corrected datasets were used for preserved analysis results.

---

## Method Summary

For each event included in the pilot study, participant scores from Q1 and Q2 were compared.

Differences between assessment periods were calculated and aggregated at the event level to evaluate relative stability.

Events displaying smaller score differences were interpreted as demonstrating greater stability across assessment periods.

Analysis 02 contributes to understanding how uncertainty assessments behave at the event level within the UTA framework.
