# UTA Pilot Data

## Overview

This folder contains the datasets used during the UTA (Uncertainty Transformation Analysis) pilot study.

The data preserved here represent the final datasets used for all published pilot analyses and associated figures.

These datasets form the empirical foundation for the pilot study results documented throughout this repository.

---

## Dataset Description

The pilot study consisted of two assessment periods:

### Q1 Dataset

Initial participant assessments collected using the UTA scoring framework.

Participants independently evaluated selected events according to the study methodology.

### Q2 Dataset

Delayed follow-up assessments collected after a waiting period.

Participants completed the evaluation process without access to their original responses, allowing delayed repeatability and stability analyses.

---

## Contents

### UTA_Q1_Pilot_Dataset.xlsx

Primary dataset containing participant responses collected during the first assessment period.

### UTA_Q2_Pilot_Dataset_Updated_v18.xlsx

Final corrected dataset containing participant responses collected during the delayed follow-up assessment period.

Version v18 represents the preserved analysis dataset used for all final pilot analyses.

---

## Data Usage

The datasets contained in this folder were used to generate:

- Analysis 01 – Delayed Repeatability
- Analysis 02 – Event Stability Audit
- Analysis 03 – Participant Stability
- Analysis 04 – Event-Type Signature Consistency

All reported pilot results originate from these preserved datasets.

---

## Data Integrity and Corrections

Throughout the pilot study, audit procedures were conducted to identify and correct data-entry and metadata issues.

Where corrections were required:

- Corrections were documented
- Audit records were preserved
- Analyses were rerun using the corrected datasets

The preserved dataset versions contained in this folder represent the final analysis-ready releases.

---

## Participant Privacy

Participant identities are not included within public research outputs.

Anonymous identifiers are used where participant-level analysis is required.

The pilot study was conducted using voluntary participation.

---

## Relationship to the Pilot Study

These datasets provide the empirical evidence supporting the pilot analyses contained within this repository.

Researchers wishing to reproduce pilot results should begin with the datasets contained in this folder.
