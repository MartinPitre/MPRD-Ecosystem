# SUANR_V2 Public GitHub Release Checklist

Use this checklist immediately before making the repository public.

- [ ] Confirm `README.md` accurately describes the current system.
- [ ] Confirm `LICENSE` is present at the repository root.
- [ ] Confirm `NOTICE.md` is present.
- [ ] Confirm `COMMERCIAL_USE.md` is present.
- [ ] Confirm `CITATION.cff` is present at the repository root.
- [ ] Confirm `THIRD_PARTY_NOTICES.md` matches the actual dependencies and datasets.
- [ ] Add a public contact method for commercial licensing inquiries.
- [ ] Replace or remove any private email addresses, API keys, tokens, credentials, or secrets.
- [ ] Check notebooks and source files for absolute local paths and personal information.
- [ ] Confirm all included images, icons, fonts, and media are yours or properly licensed.
- [ ] Confirm copied or adapted code contains required third-party notices.
- [ ] Confirm dataset redistribution is permitted before committing raw dataset files.
- [ ] Confirm dependency names and versions from the actual environment.
- [ ] Confirm benchmark results are clearly labeled and reproducible.
- [ ] Confirm experimental claims do not exceed the available evidence.
- [ ] Tag the first public release after the repository contents are final.
- [ ] Consider creating an archived release/DOI later and update `CITATION.cff` if one is assigned.
